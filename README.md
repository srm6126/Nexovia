# SHAHIN APP — Starter Website Source v2

## আপডেট
- DSR SALES STATEMENT এবং আজকের নতুন মাল বাটন সারাংশ কার্ডের ঠিক নিচে আনা হয়েছে।
- মোবাইল ড্যাশবোর্ডের কার্ড, দ্রুত কাজের অপশন, টার্গেট অংশ ও নিচের নেভিগেশন আরও কমপ্যাক্ট করা হয়েছে।
- প্রতিটি মেনু/কার্ড নিজস্ব মডিউল পেজ খুলবে এবং পেজ পরিবর্তনের সময় উপরে যাবে।
- টেবিলের কলাম শিরোনাম বাংলায় দেখাবে।

## GitHub-এ আপডেট
1. Repository খুলুন।
2. `index.html` খুলে Edit (পেন্সিল) দিয়ে পুরোনো কোড পুরো বদলান, অথবা পুরোনো `index.html` মুছে নতুনটি Upload করুন।
3. Commit changes দিন।
4. GitHub-এর সঙ্গে Vercel যুক্ত থাকলে নতুন Deployment স্বয়ংক্রিয়ভাবে শুরু হবে।
5. Vercel Deployments-এ Ready হলে ওয়েবসাইট Refresh করুন।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
এটি একক HTML Frontend starter। ডাটা ব্রাউজারের localStorage-এ থাকে। ডেমো PIN প্রকৃত Authentication নয়। একাধিক কর্মী/ডিভাইস, কোম্পানি আলাদা রাখা, নিরাপদ PIN, অনুমতি, ব্যাকআপ ও নির্ভরযোগ্য হিসাবের জন্য Cloud Database এবং server-side security যুক্ত করতে হবে।
