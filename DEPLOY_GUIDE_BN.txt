VERCEL PREVIEW + ANDROID PWA — নির্দেশিকা
========================================
1. ZIP extract করে index.html, manifest.webmanifest, sw.js এবং icons/ একই project root-এ রাখুন।
2. Vercel-এ আগে Preview deployment তৈরি করুন; Production alias/ডোমেইন পরিবর্তন করবেন না।
3. Supabase project URL ও anon/publishable key public client config হতে পারে; service_role key কখনো browser code বা ZIP-এ দেবেন না।
4. SQL চালানোর আগে database backup নিন এবং public.businesses, app_state, pin_accounts, pin_sessions-এর schema মিলিয়ে নিন।
5. ORIGINAL_PIN_CLOUD_SETUP_REFERENCE_ONLY.sql reference মাত্র; বর্তমান database-এ একই objects থাকলে পুনরায় চালাবেন না।
6. Preview URL-এ blank page হলে নতুন boot diagnostic-এ JavaScript error দেখানোর কথা; CDN/Supabase script লোড না হলে নেটওয়ার্ক ও Console পরীক্ষা করুন।
7. Android PWA: HTTPS Preview URL Chrome-এ খুলুন → ⋮ → Install app / Add to Home screen।
8. Native APK: android-capacitor/ starter; Android Studio/Gradle build, package ID, signing keystore এবং physical device test আবশ্যক। এই ZIP-এ signed APK নেই।

Production-এ দেওয়ার আগে QA_CHECKLIST_BN.txt-এর সব পরীক্ষা পাস করুন।
