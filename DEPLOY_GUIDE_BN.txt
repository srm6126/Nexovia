SHAHIN APP ATC — VERCEL DEPLOYMENT
==================================
1) ZIP extract করুন। Extract করা folder-এর ভেতরে index.html, api/ এবং vercel.json থাকতে হবে।
2) GitHub repository-তে folder-এর CONTENTS upload করুন (folder-এর ভেতরের ফাইলগুলো root-এ থাকবে), তারপর Vercel-এ Import করুন। অথবা Vercel CLI দিয়ে এই folder deploy করুন।
3) Vercel Project > Settings > Environment Variables-এ GEMINI_API_KEY যোগ করুন। API key শুধু server-side variable; index.html-এ দেবেন না।
4) Production deploy-এর আগে Preview URL-এ Admin PIN দিয়ে পরীক্ষা করুন। Scanner: চালান ছবি > AI দিয়ে স্ক্যান > পণ্য/পরিমাণ যাচাই > Confirm। Support: 🤖 আইকন > প্রশ্ন লিখুন।
5) Supabase-এর বিদ্যমান PIN RPC ও app_state কাঠামো ব্যবহার করা হয়। এই প্যাকেজ কোনো live database migration স্বয়ংক্রিয়ভাবে চালায় না।
6) আগে থেকে থাকা live app replace করবেন না। Preview পরীক্ষা, JSON backup, তারপর আলাদা deployment decision নিন।

AI CONFIGURATION
----------------
- GEMINI_API_KEY না থাকলে AI Scanner/AI Support কাজ করবে না; Scanner-এ manual entry থাকবে এবং Support স্থানীয় FAQ fallback দেখাবে।
- API key Vercel server environment-এ রাখতে হবে। Client-side-এ প্রকাশ করা যাবে না।

KNOWN LIMITATIONS — READ BEFORE PRODUCTION
------------------------------------------
- এই release-এ AI Scanner ও AI Support-এর server routes যোগ হয়েছে; OCR ফলাফল ভুল হতে পারে, তাই Confirm-এর আগে প্রতিটি পণ্য ও পরিমাণ যাচাই বাধ্যতামূলক।
- Support ticket-গুলো বর্তমান app_state JSON-এ থাকে; আলাদা ticket table নয়।
- বিদ্যমান pin_save_state পুরো JSON প্রতিস্থাপন করে। concurrent multi-device edit conflict এখনো সম্পূর্ণ সমাধান করা হয়নি।
- Central/DSR/General stock ledger-এর সব movement atomic database transaction-এ স্থানান্তর করা হয়নি।
- Live Supabase RLS, RPC permission এবং real multi-device concurrency এখানে থেকে পরীক্ষা করা হয়নি।
- Native APK build/sign করা হয়নি; এটি Web/PWA deployment package।
