ANDROID APK BUILD — STARTER
==========================
প্রয়োজন: Node.js LTS, Android Studio, Android SDK/Gradle, এবং signing keystore।

1) এই ফোল্ডারে terminal খুলুন।
2) npm install
3) npx cap add android (প্রথমবার)
4) npx cap sync android
5) npx cap open android
6) Android Studio-তে Gradle sync করুন; package ID ও app icon যাচাই করুন।
7) Debug APK build করে বাস্তব ফোনে পরীক্ষা করুন।
8) Release APK/AAB তৈরি করতে নিজের keystore দিয়ে sign করুন এবং keystore নিরাপদে রাখুন।

এটি starter source; build/signing করা APK নয়। Capacitor build-এর আগে Supabase URL/key, network permission, app lifecycle, PWA service worker এবং offline behavior পরীক্ষা করুন।
