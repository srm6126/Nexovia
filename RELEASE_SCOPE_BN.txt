SHAHIN APP — RELEASE SCOPE / A-TO-Z STATUS
==========================================

এই ফাইলটি বাস্তব অবস্থা জানায়; কোনো অসম্পূর্ণ অংশকে সম্পন্ন বলে দাবি করে না।

অ্যাপের অন্তর্ভুক্ত বিদ্যমান মডিউল
--------------------------------
- Admin / Dealer / Manager / DSR PIN login UI ও role-based page permissions
- Dashboard, product master, buy/sell rates, DSR sales statement
- Damage quantity/value, cash, due, previous due, total due
- General stock, company receipt/challan, central stock ও DSR allocation-এর আংশিক UI/state
- Expenses, income/ledger, due adjustment, reports, PDF/PNG/share hooks
- Backup/restore, settings, audit-like history, support FAQ/voice, scanner review/manual fallback
- PWA manifest, service worker, icons

এই প্যাকেজে সংশোধন
------------------
- Dashboard stock valuation এখন general + central company + DSR vehicle stock-এর buy-price value যোগ করে।
- Startup/runtime JavaScript error হলে blank page-এর বদলে error diagnostic দেখানোর ব্যবস্থা যোগ।
- Vercel/PWA/Native Android setup docs হালনাগাদ।

Production-ready হওয়ার আগে এখনো আবশ্যক
--------------------------------------
1. Legacy whole-state pin_save_state-কে secure role-scoped, transactional RPC/data model-এ migrate করা; concurrent edits/conflict resolution পরীক্ষা।
2. Stock movement ledger-কে app forms-এর সব add/edit/delete/restore path-এর সঙ্গে atomicভাবে যুক্ত করা। বর্তমানে তিন bucket UI/state আছে, কিন্তু পূর্ণ transaction-safe end-to-end ledger নয়।
3. DSR issue/return/carry-forward এবং historical edit replay/dependency protection সম্পূর্ণ করা। বর্তমান DSR record issue/return থেকে sold হিসাব করে; পরদিন carry-forward pipeline পূর্ণ নয়।
4. Nested carton → crate → leaf → base conversion এবং প্রতি receipt-এ conversion snapshot সব flow-তে বাধ্যতামূলক করা। বর্তমান UI-তে one-level conversion।
5. OCR: TextDetector browser-dependent; reliable Bengali challan OCR নয়। Manual review fallback আছে।
6. Support ticket real central DB notification/reply-তে migrate করা; বর্তমান support state app JSON-এ।
7. Supabase staging integration, RLS/policies, PIN account authorization, multi-device sync, backup/restore, race-condition tests।
8. Vercel Preview browser tests, Android PWA device tests, APK build/signing and install test।

গুরুত্বপূর্ণ হিসাব নিয়ম
---------------------
DSR net sale = gross sale - damage value; today due = net sale - cash (negative হলে আলাদা credit rule যাচাই করতে হবে); total due = previous due + today due। Damage value যেন profit/sales-এ দ্বিতীয়বার বাদ না যায়।
Stock valuation = (general + central + DSR vehicle quantity) × buy price, পণ্যভিত্তিক।
