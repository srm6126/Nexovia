SHAHIN APP – FINAL UPDATE PACKAGE

এই প্যাকেজটি আপনার আগের SHAHIN APP-এর ওপর আপডেট। পুরোনো হিসাব/হিস্টরি ডাটাবেস থেকে মুছে ফেলার কোনো মাইগ্রেশন নেই।

DEPLOY:
1) ZIP খুলে ভেতরের সব ফাইল একই Vercel প্রজেক্টের Root folder-এ আপলোড করে Replace/Deploy করুন।
2) Chrome-এ ওয়েবসাইট খুলে Refresh করুন। নতুন Service Worker cache version দেওয়া আছে।
3) Admin PIN দিয়ে Settings > Edit চালু করে প্রয়োজনীয় সেটিংস ব্যবহার করুন।

নতুন সুবিধা:
- রিপোর্টে DSR-এর তারিখভিত্তিক পণ্যওয়ারি দেওয়া, ফেরত, ড্যামেজ, বিক্রি, রেট, টাকা, নগদ ও বকেয়া।
- রিপোর্ট PDF/Print, PNG ছবি এবং Share। প্রিন্টে রিপোর্ট এক A4 পৃষ্ঠায় ফিট করার চেষ্টা করে।
- Settings-এ প্রতিটি DSR-এর টার্গেট নিয়ন্ত্রণ।
- Settings থেকে আগের তারিখের স্টক যোগ/কমানো/নির্ধারণ। আগের দিনের বিক্রি DSR পেজে তারিখ বদলে যোগ করা যাবে।
- নির্বাচিত হিসাব ক্লিয়ার করা যায়; পণ্যের তালিকা, রেট, স্টক ও অ্যাকাউন্ট অক্ষত থাকে।
- সব হিসাব রিসেট বাটনও এখন লেনদেনের হিসাব পরিষ্কার করে; পণ্য/রেট মুছে না।
- অ্যাকাউন্ট ব্যান/আনব্যানের জন্য SQL প্যাচ অন্তর্ভুক্ত।

IMPORTANT – একবার SQL চালাতে হবে:
Supabase > SQL Editor-এ SHAHIN_ACCOUNT_BAN_PATCH.sql-এর সম্পূর্ণ কোড পেস্ট করে Run করুন। এটি Admin-only account ban/unban RPC যোগ করে। এটি না চালালে অ্যাকাউন্ট ব্যান/আনব্যান বাটনে SQL function missing দেখাবে।

নোট: PNG তৈরির জন্য html2canvas CDN ব্যবহার করা হয়েছে; PNG export করার সময় ইন্টারনেট সংযোগ থাকতে হবে। PDF তৈরিতে ব্রাউজারের Print > Save as PDF ব্যবহার করুন।
