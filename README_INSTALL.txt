SHAHIN APP - Updated PWA package

Upload ALL files and folders in this package to the ROOT of the same Vercel project:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

The SQL file is included for reference only. If the setup SQL was already run successfully, DO NOT run it again.

After deploying, open the site in Chrome, reload once, wait a little, then use Chrome menu > Install app.
Idle logout is set to 30 minutes by default and can be changed in Settings.
