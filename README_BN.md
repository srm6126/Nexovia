# SHAHIN APP — নতুন GitHub/Vercel প্যাকেজ

## GitHub-এ আপলোড
1. ZIP Extract করুন।
2. Extract করা ফোল্ডারের ভেতরের সব ফাইল GitHub Repository-এর Root-এ আপলোড করুন।
3. `node_modules` বা `dist` আপলোড করবেন না।
4. Vercel-এ Repository Import করুন।
5. Framework Preset: `Vite`, Build Command: `npm run build`, Output Directory: `dist` দিন।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
এই সংস্করণে ডেটা যে ফোন/ব্রাউজারে এন্ট্রি করা হবে, সেই ডিভাইসের Browser Storage-এ থাকবে। একাধিক ফোনে একই ডেটা লাইভ Sync হবে না। Vercel শুধু ওয়েবসাইট Host করে; Cloud Database নয়। একাধিক ডিভাইসে নিরাপদে ব্যবহার করতে Supabase বা অন্য Backend-এর Authentication, Database ও Access Policy আলাদাভাবে সংযুক্ত ও পরীক্ষা করতে হবে।

## হিসাবের নিয়ম
- বিক্রি = দেওয়া − ফেরত − ড্যামেজ
- সেভ করলে স্টক থেকে দেওয়া কমবে এবং ফেরত যোগ হবে।
- বিক্রির টাকা = বিক্রির সংখ্যা × বিক্রয় রেট
- আজকের বকেয়া = বিক্রির টাকা − নগদ জমা (ঋণাত্মক হলে শূন্য)
- পূর্বের বকেয়া = আগের সেভ করা বকেয়া + ম্যানুয়াল সমন্বয়

ব্যবসার আসল হিসাব ব্যবহারের আগে সব হিসাব যাচাই করুন এবং নিয়মিত JSON Backup রাখুন।
